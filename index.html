Installation

📦 Via NPM (Recommended)

npm install @squidjam/qrcode-element
import '@squidjam/qrcode-element';

🌐 Via CDN (UMD)

<script src="https://unpkg.com/@squidjam/qrcode-element@latest/dist/qrcode-element.umd.js"></script>

📄 Direct Module Import

<script type="module" src="path/to/qrcode-element.js"></script>

Basic Usage

🎯 Simplest Example

<qr-code data-text="Hello World"></qr-code>

⚙️ With Options

<qr-code 
  data-text="https://example.com"
  data-width="256"
  data-height="256"
  data-render="canvas"
  data-foreground="#000000"
  data-background="#ffffff"
  data-error-level="0"
></qr-code>

💻 JavaScript / TypeScript

const qrcode = document.createElement('qr-code');
qrcode.text = 'Dynamic Content';
qrcode.width = 200;
qrcode.height = 200;
qrcode.renderType = 'svg';

document.body.appendChild(qrcode);

// Listen for generation complete
qrcode.addEventListener('qrcode-ready', (event) => {
  console.log('QR Code generated:', event.detail);
});

📋 Attributes

data-text (required) - Text or URL to encode

data-width (number, default: 256) - Width in pixels

data-height (number, default: 256) - Height in pixels

data-render (string, default: canvas) - Render type: canvas or svg

data-foreground (hex, default: #000000) - Foreground color

data-background (hex, default: #ffffff) - Background color

data-error-level (0-3, default: 0) - Error correction level
